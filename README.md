# L'Équipe Salon — Multilingual Salon Web Application

A modern, mobile-first website template designed for European hair and styling salons. Built with a focus on clean visual aesthetics, fast performance, and instant international accessibility.



## ✨ Key Features
* **Multilingual Toggle:** Seamless switching between **Italian (Default), English, German, and French** to serve both local residents and international visitors.
* **Service & Pricing Menu:** Clean, categorized layout for women's styling, men's cuts, coloring, and treatments.
* **Mobile-First Conversion:** Direct click-to-call actions, integrated location mapping, and quick appointment prompts.
* **Fast & Responsive:** Optimized production build engineered for instant loading on mobile devices.

## 🛠️ Tech Stack
* **Frontend:** React, TypeScript
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
